# Kaskad — Теорія В'юненка K3

[Русский](README.md) · [English](README.en.md) · [简体中文](README.zh-CN.md)

> **Kaskad** — математичний дослідницький корпус Теорії В'юненка K3. Його ядро — скінченна позиційна система з основою 1000; розширення досліджують арифметику, структуру записів, подільність і пов'язані математичні простори. Теорія, обчислювальні перевірки та програмна реалізація розглядаються окремо.

## 1. Математичне ядро

Фіксуємо
[
B=1000=10^3=2^3cdot5^3,qquad D_B={0,1,ldots,999}.
]

Канонічний каскад — скінченний вектор
[
a=(a_m,ldots,a_1,a_0),qquad a_iin D_B,
]
де (a_0) — молодша позиція. Його значення задає
[
operatorname{Val}_{K3}(a)=sum_{i=0}^{m}a_iB^i.
]

Для додатного значення старший коефіцієнт ненульовий; нуль має єдину форму ((0)). Знакове розширення розглядається окремо.

## 2. Позиція має значення

Символ `k` розділяє сусідні групи. Це не цифра, основа, множник чи оператор множення. Лише межа `k` переводить читання до наступного степеня 1000; кількість десяткових цифр у групі не створює нової позиції.

| Запис | Коефіцієнти від старшої позиції | Значення |
|---|---:|---:|
| `1k` | ((1,0)) | (1,000) |
| `50k0k7` | ((50,0,7)) | (50,000,007) |
| `50k0k` | ((50,0,0)) | (50,000,000) |

Завершальний `k` позначає рівно одну пропущену нульову молодшу групу. Явні нульові групи також зберігають свої позиції. Не можна вилучати, переставляти чи об'єднувати нулі й роздільники без доведення еквівалентності: однакова глибина не означає однакового значення.

## 3. Режими та рівність

- **Канонічний режим** приймає лише записи суворої граматики K3.
- **K3-PAD** — явно обраний режим імпорту й нормалізації неканонічних груп; він не змінює суворий розбір.
- **K3-RAW** зберігає початкову структуру операндів і їхній порядок для структурного аналізу.

Рівність текстів, коефіцієнтних структур, числових значень, дерев виразів і слідів операцій — різні відношення. Однаковий результат не робить записи або історії обчислень тотожними. Оператор зсуву (S_B) визначено окремо від символу `k`.

## 4. Арифметика та розширення

Перенесення й позичання описує один закон балансу:
[
c_i+t_i=1000t_{i+1}+r_i,qquad 0le r_ile999.
]
Допустима нормалізація зберігає зважене значення; докази й умови наведено в профільних розділах.

Для складеної основи китайська теорема про лишки дає при (rge1)
[
mathbb Z/1000^rmathbb Zcong
mathbb Z/2^{3r}mathbb Z	imesmathbb Z/5^{3r}mathbb Z.
]
Відповідне поповнення — кільце (mathbb Z_2	imesmathbb Z_5), а не поле. CRT і нескінченні каскади є окремим топологічним розширенням і не змінюють скінченної семантики K3.

## 5. Предмет і межі

K3 задає точне подання цілих чисел і досліджує його позиційні, алгебраїчні, подільні, комбінаторні й топологічні властивості. Вимірювання, фізичні одиниці, статистичні дані, графи та програмні сутності потребують власних типів, одиниць і явних відображень; вони не стають числами K3 автоматично.

Арифметика значень K3 узгоджується з класичною арифметикою цілих. Відмінність конструкції — у позиційній формі, канонічній мові та досліджуваних структурних розширеннях.

## 6. Статус тверджень

Означення вводять об'єкти; постулати фіксують домовленості; теореми потребують доведень; класичні результати зберігають джерела й умови. Тест підтверджує лише перевірені входи, а не загальне твердження. Специфікація чи гіпотеза не є фактом реалізації або встановленим результатом.

# Kaskad — позиційна система числення з основою 1000

**Kaskad** — математичний дослідницький проєкт. Його основний напрям, **Теорія В'юненка K3**, вивчає запис цілих чисел групами по три десяткові цифри та математичні властивості таких записів.

Мета K3 — точно визначити цей запис, описати операції над ним і дослідити його властивості, не підмінюючи доведення обчисленнями.

## K3 за одну хвилину

У звичайному десятковому записі число 50 000 007 записується як **50 000 007**. У K3 його можна записати групами по три цифри:

**50k0k7**

Тут **k** — роздільник груп. Він не означає множення і сам по собі не є числом.

| Запис | Групи від старшої до молодшої | Значення |
|---|---:|---:|
| **7** | (7) | 7 |
| **1k** | (1, 0) | 1 000 |
| **50k0k7** | (50, 0, 7) | 50 000 007 |
| **50k7** | (50, 7) | 50 007 |
| **50k0k** | (50, 0, 0) | 50 000 000 |

Середній нуль у **50k0k7** займає окрему позицію. Якщо його прибрати, число зміниться: **50k7 = 50 007**. Тому нулі й роздільники не можна видаляти або переставляти без точного правила та доведення збереження потрібної властивості.

## Три основні визначення

**1. Основа.** У K3 зафіксовано основу

\[
B=1000=10^3=2^3\cdot5^3.
\]

Допустимі значення коефіцієнта однієї групи:

\[
D_B=\{0,1,\ldots,999\}.
\]

Приклад: **50** — допустимий коефіцієнт. Контрприклад: **1000** не може бути коефіцієнтом однієї канонічної групи.

**2. Каскадний вектор.** Це скінченна послідовність коефіцієнтів

\[
a=(a_m,\ldots,a_1,a_0),\qquad a_i\in D_B,
\]

де індекс \(i\) задає степінь основи. Запис перелічує групи від старшої до молодшої; значення обчислюється від молодшої позиції до старшої.

Приклад: запису **50k0k7** відповідає вектор \((50,0,7)\). Контрприклад: \((50,1000,7)\) не є канонічним каскадним вектором, оскільки коефіцієнт 1000 виходить за допустимий діапазон.

**3. Числова оцінка.** Функція переводить скінченні вектори коефіцієнтів у невід'ємні цілі числа:

\[
\operatorname{Val}_{K3}:
\bigcup_{m\ge0}D_B^{m+1}\to\mathbb N_0,
\qquad
\operatorname{Val}_{K3}(a)=\sum_{i=0}^{m}a_iB^i.
\]

Приклад:

\[
\operatorname{Val}_{K3}(50,0,7)
=50\cdot1000^2+0\cdot1000+7
=50\,000\,007.
\]

Контрприклад до хибного прочитання: **50k0k7** — це не \(50\cdot7\), а **k** не є знаком множення.

**Розрізняйте три об'єкти:** текстовий рядок **50k0k7**, вектор \((50,0,7)\) і ціле число \(50\,000\,007\). Вони пов'язані правилом читання, але це різні типи об'єктів.

## Що саме досліджує K3

K3 розглядає скінченні позиційні записи, їхню канонічну форму, переноси й позики, арифметичні операції, подільність, лишки та окремі топологічні розширення.

Числова арифметика K3 узгоджується зі звичайною арифметикою цілих чисел: основа 1000 групує десяткові цифри по три. Проєкт не стверджує, що звичайні цілі числа або їхню арифметику замінено новою системою. Робота зосереджена на точній мові запису, позиційній структурі, збереженні нульових груп та окремо формалізованих розширеннях. Порівняння з відомою математикою наведено в [огляді класичних відповідностей](docs/CLASSICAL_MATHEMATICS_CROSSWALK.md).

У репозиторії є й інші напрями. Наприклад, **CV-1** — окрема математична модель зі своїми об'єктами та визначеннями. Вона не стає частиною аксіоматики K3 лише через те, що документи розміщені в одному репозиторії.

## Статус результатів та обмеження

Статус належить конкретному твердженню, а не репозиторію загалом. У [реєстрі K3](docs/K3_CLAIM_REGISTRY.json) наразі 52 записи:

| Записи реєстру | Кількість | Що це означає |
|---|---:|---|
| Визначення | 13 | Об'єкти й терміни задано |
| Доведення очікують незалежної перевірки | 14 | Текст доведення зареєстровано; незалежну перевірку не зафіксовано |
| Класичні спеціалізації очікують незалежної перевірки | 7 | Використано відомі математичні результати; перевірку формулювання й умов не зафіксовано |
| Відкриті гіпотези | 10 | Потрібне доведення або контрприклад |
| Контрприклади | 5 | Зафіксовано конкретні випадки, що спростовують надто широкі твердження |
| Прикладні моделі, не теореми | 2 | Вони описують застосування, але не доводять коректність програм |
| Перевірка цілісності каталогу очікує CI | 1 | Перевірку ще не зареєстровано як завершену |

У реєстрі наразі немає записів про незалежну перевірку цих 52 пунктів. Це не означає, що всі твердження хибні; це означає, що незалежну перевірку документально не підтверджено.

**Проєкт не заявляє:**

- що всі розширення K3 уже доведено;
- що обчислювальні тести доводять твердження для всіх цілих чисел;
- що всі результати пройшли незалежне рецензування;
- що проєкт отримав зовнішню академічну акредитацію чи визнання;
- що прикладні моделі означають готові або перевірені програмні інтеграції.

Відомі межі, невдалі узагальнення та відкриті питання зібрані в [каталозі контрприкладів і меж](docs/K3_COUNTEREXAMPLES_AND_BOUNDARIES.md). Поточні обмеження обчислювальної частини описані в [статусі розробки](docs/DEVELOPMENT_STATUS.md).

## Перевірка обчислювальної реалізації

У репозиторії є допоміжний пакет **src/kaskad_k3/**, тести в **tests/** та еталонні дані в **tests/vectors/**. Пакет використовує стандартну бібліотеку Python і не має додаткових runtime-залежностей. Конфігурація CI охоплює Python 3.11–3.14.

Запуск із кореня репозиторію:

~~~bash
PYTHONPATH=src python -m unittest discover -s tests -v
~~~

У Windows PowerShell:

~~~powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
~~~

Тести перевіряють конкретні випадки розбору й форматування, обчислення коефіцієнтів, нормалізації, арифметики, ділення, подільності, серіалізації та еталонних векторів. Вони не доводять загальні теореми й не перевіряють усі математичні розширення.

Перевіряйте CI для конкретного commit у [GitHub Actions](https://github.com/Ivan-VHS/Kaskad/actions). Для вихідної ревізії main — **eac38c147001ea554b3afdad2e659000ef1404e6** — на момент підготовки цієї редакції GitHub не повернув записів про status checks. Тому README не стверджує, що поточна main пройшла CI.

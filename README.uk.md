# Kaskad — Теорія В'юненка K3

**Математика, у якій позиція має значення.** Kaskad — дослідницький корпус про каскадно-тисячні числа, їхню арифметику, структуру, подільність і розширення. Модель відокремлена від програмного коду, а обчислення не видаються за доведення.

> **Принцип K3:** значення визначають коефіцієнти та їхні позиції; роздільник позначає перехід, а нуль зберігає своє місце.

## ◈ Візуальна мова Kaskad

## 1. Математичне ядро

Теорія В'юненка K3 фіксує складену основу

\[
B=1000=10^3=2^3\cdot5^3,\qquad D_B=\{0,1,\ldots,999\}.
\]

Скінченний каскад — вектор

\[
a=(a_m,\ldots,a_1,a_0),\qquad a_i\in D_B,
\]

де $a_0$ — молодша група. Значення задає

\[
\boxed{\operatorname{Val}_{K3}(a)=\sum_{i=0}^{m}a_i\,1000^i.}
\]

Для додатного каскаду старший коефіцієнт ненульовий; нуль має форму $(0)$. Знакове розширення окреме.

### Читання каскаду

Символ **k** розділяє групи. Це лише роздільник, не цифра, множник, основа чи оператор множення. Кожен роздільник переводить до наступного степеня $1000$; кількість цифр у групі не створює позицій.

| Запис | Коефіцієнти від старшої групи | Значення |
|---|---:|---:|
| **7** | $(7)$ | $7$ |
| **1k** | $(1,0)$ | $1,000$ |
| **1k0k1** | $(1,0,1)$ | $1,000,001$ |
| **50k0k7** | $(50,0,7)$ | $50,000,007$ |
| **50k0k** | $(50,0,0)$ | $50,000,000$ |
| **12k34k56** | $(12,34,56)$ | $12,034,056$ |

Завершальний **k** позначає рівно одну пропущену нульову молодшу групу. Явний нуль також займає позицію. Не можна вилучати чи об'єднувати нулі й роздільники без доведення еквівалентності: глибина та значення різні.

## 2. Канонічна форма й режими

| Режим | Призначення |
|---|---|
| **Canonical** | Суворий розбір слів канонічної граматики K3 |
| **K3-PAD** | Явно обраний імпорт і нормалізація неканонічних токенів |
| **K3-RAW** | Структурний вхід зі збереженням груп, порядку й форми операнда |

Нормалізація не виконується мовчки. Розрізняються рівність рядків, коефіцієнтних векторів, числових значень, упорядкованих дерев виразів і слідів операцій. Однакові числа не роблять тотожними записи чи історії обчислення. Оператор зсуву $S_B$ окремий від роздільника.

## 3. Каскадний баланс

Перенесення й позичання — випадки одного закону:

\[
\boxed{c_i+t_i=1000t_{i+1}+r_i,\qquad 0\le r_i\le999.}
\]

Тому

\[
t_{i+1}=\left\lfloor\frac{c_i+t_i}{1000}\right\rfloor,
\qquad r_i=c_i+t_i-1000t_{i+1}.
\]

Допустима нормалізація зберігає зважену суму:

\[
\sum_i c_i1000^i=\sum_i r_i1000^i.
\]

## 4. Складена основа й розширення

Для $1000=2^3\cdot5^3$ китайська теорема про лишки дає при $r\ge1$

\[
\mathbb Z/1000^r\mathbb Z\cong
\mathbb Z/2^{3r}\mathbb Z\times\mathbb Z/5^{3r}\mathbb Z.
\]

Відповідне поповнення — топологічне кільце

\[
\widehat{\mathbb Z}_{1000}\cong\mathbb Z_2\times\mathbb Z_5,
\]

а не поле. Додаткові шари охоплюють подільність, ультраметрику, нескінченні каскади, структурну семантику, комбінаторику, статистику й тензорні інваріанти. Кожен має власну область і статус та не змінює ядро без версії й обґрунтування.

## 5. Теорія В'юненка та ТЧВ

**Теорія В'юненка K3** — формальне ядро Kaskad: скінченні каскади, канонічне позиційне подання, поліноміальна оцінка й сумісні розширення.

**ТЧВ** згадується як суміжний дослідницький контекст і лишається окремим теоретичним напрямом. Це не ототожнює його з K3 і не переносить твердження однієї системи до аксіоматики іншої. Зв'язок потребує явних об'єктів, відображень, припущень і перевірюваних положень.

## 6. Статуси тверджень

| Маркер | Статус | Значення |
|---|---|---|
| **DEF** | Означення | Об'єкт має явну область |
| **AX** | Постулат | Зафіксовано вихідну домовленість |
| **THM** | Теорема | Наведено повне доведення |
| **CLASSIC** | Класичний результат | Вказані джерело й умови |
| **CHECK** | Обчислювальна перевірка | Перевірено конкретні входи/скінченну область |
| **SPEC** | Специфікація | Описано вимоги чи модель |
| **HYP** | Гіпотеза | Твердження лишається відкритим |
| **IMPL** | Факт реалізації | Є код і відтворювана перевірка |

Тест не замінює доведення. Скінченний перебір стосується лише перевіреної області. Відсутність перевірки — не PASS; реалізація не визначає математичний зміст.

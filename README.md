## Канонические параметры

| Параметр | Значение |
|---|---|
| Название | Теория Вьюненко |
| Система | K3 |
| Основание | \(B=1000=10^3=2^3\cdot5^3\) |
| Разделитель каскадных групп | \(k\) |
| Базовая область | \(\mathbb N_0\) |
| Знаковое расширение | \(\mathbb Z\) |
| Топологическое пополнение по делимости на \(1000^r\) | \(\mathbb Z_2\times\mathbb Z_5\) |

**Позиционное правило:** число разделителей определяет глубину K3, но не точное значение. Значение задаётся коэффициентами всех групп: 50k0k = 50 000 000, а 5k0k = 5 000 000. Неканонический ввод 5k00k принимается только в отдельно включаемом режиме импорта с дополнением нулями и нормализуется к 5k0k.

## Математический статус

K3 — авторская формальная организация позиционной арифметики с основанием 1000. Её неотрицательные значения изоморфны \(\mathbb N_0\), а знаковое расширение — \(\mathbb Z\). Система не заявляет об отмене стандартной арифметики или об универсальном превосходстве над другими основаниями.

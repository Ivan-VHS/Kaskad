# Kaskad — Теория Вьюненко K3

> **Позиция имеет вес. Ноль сохраняет место. Доказательство ставит печать.**

## 1. Каноническая модель K3

Основание системы фиксировано:

\[
B=1000=10^3=2^3\cdot5^3.
\]

Каждая группа задаёт целый коэффициент \(a_i\) в диапазоне \(0\le a_i\le999\). Разделитель **k** отделяет соседние группы; позиция группы определяет степень основания. Для конечного каскада

\[
N=\sum_{i=0}^{m}a_i\,1000^i.
\]

Чтение начинается с младшей группы справа: её вес равен \(1000^0\), следующей — \(1000^1\), далее — \(1000^2\) и так далее. Точный числовой результат задаётся **всеми коэффициентами и их позициями**, а не количеством разделителей.

| Запись | Позиционное разложение | Значение |
|---|---|---:|
| **12k34k56** | \(12\cdot1000^2+34\cdot1000+56\) | 12 034 056 |
| **50k0k7** | \(50\cdot1000^2+0\cdot1000+7\) | 50 000 007 |
| **50k0k** | \(50\cdot1000^2+0\cdot1000+0\) | 50 000 000 |
| **5k0k** | \(5\cdot1000^2+0\cdot1000+0\) | 5 000 000 |

**Нулевые группы не удаляются автоматически.** Ноль — коэффициент конкретной позиции, а не разрешение сдвинуть соседние группы. Число разделителей характеризует глубину записи, но не определяет значение без самих коэффициентов.

### Разделение режимов

- **Каноническая запись K3** — строгий язык с однозначной грамматикой и позиционной оценкой.
- **K3-PAD** — явно включаемый режим нормализующего импорта; он не меняет строгую каноническую грамматику.
- **K3-RAW** — структурный вход, в котором сохраняются исходные операнды и порядок; его нельзя молча отождествлять с каноническим числом.

## 3. Как читать научные утверждения

В Kaskad внешний вид не заменяет доказательство. В документах необходимо различать:

| Метка | Значение |
|---|---|
| **Определение** | вводит объект, область определения или операцию |
| **Теорема / доказано** | утверждение сопровождается предпосылками и доказательством |
| **Спецификация** | фиксирует требуемую формальную модель или поведение |
| **Предложение** | авторская конструкция, требующая дальнейшего обоснования |
| **Гипотеза / открытая задача** | результат не считается установленным |
| **Внешний источник** | классическая теория, исследовательский материал или исходный проект, на который дана ссылка |

Наличие формулы в документе не делает её автоматически теоремой. Исследовательская дорожная карта не является отчётом о завершённых работах, а прикладная модель не доказывает свойства программной реализации.

## 4. Визуальный кодекс

Документация оформляется как полевой математический атлас:

- **Обсидиан** задаёт спокойный фон и чёткие границы.
- **Нефрит** отмечает каноническую структуру, определения и проверенные инварианты.
- **Янтарь** отмечает исследовательские переходы, примеры и ссылки на первоисточники.
- **Маджента** допускается как редкий маркер аномалии, конфликта или неподтверждённого участка, но не как обозначение доказанности.

GitHub README остаётся Markdown-документом: схемы — SVG и Mermaid, раскрывающиеся выводы — через HTML-элемент details, таблицы — только там, где они улучшают сравнение. Внешние CDN, удалённые веб-шрифты, декоративные счётчики без данных и фиктивная статистика не используются. Подробности — в [редакционном кодексе](docs/JADE_ATLAS_STYLE.md).

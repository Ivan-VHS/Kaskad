# Kaskad — математический исследовательский корпус Теории Вьюненко K3

Kaskad предназначен для постоянной работы над математикой: построения точных определений, исследования структур, постановки задач, доказательства теорем, поиска контрпримеров и развития математических связей. Это математический исследовательский репозиторий, а не программный продукт.

**Фундаментальная система:** Теория Вьюненко K3.  
**Основание K3:** \(B=1000=10^3=2^3\cdot5^3\).  
**Разделитель групп:** \(k\).  
**Постоянный приоритет:** математическая корректность, формализация и доказательство.

## Постоянное назначение

Основной исследовательский цикл:

**математический вопрос → классический контекст → точное определение → формальная модель → доказательство или контрпример → точная/численная проверка следствий → независимая математическая проверка → публикация.**

K3 не объявляется заменой классической арифметики. Канонические неотрицательные каскады взаимно однозначно представляют \(\mathbb N_0\), а знаковое расширение — \(\mathbb Z\). Математическая ценность теории формулируется через её канонический язык, позиционную структуру, нормализацию, остаточные деревья, составное основание и доказанные для этих конструкций результаты.

## Границы репозитория

1. **Математика — единственный постоянный предмет работы Kaskad.** Исследуются математические объекты и связи между математическими дисциплинами.
2. Kaskad не является репозиторием операционной системы, языка программирования, IDE, драйверов, прикладных программ или универсальной программной платформы.
3. Связи с другими репозиториями и проектами допускаются только в математическом смысле: формальные модели, определения, отображения, примеры, аналогии с чёткими границами и доказуемые следствия. Программные зависимости и интеграционные задачи не входят в предмет Kaskad.
4. Код, скрипты и вычислительные инструменты могут использоваться только как вспомогательные средства проверки документов, точной арифметики, конечного перебора, воспроизводимого эксперимента или формальной верификации. Они не являются самостоятельной целью репозитория и не заменяют доказательство.
5. Вычислительный или экспериментальный результат никогда автоматически не повышает гипотезу до теоремы.

## Канонические параметры K3

| Параметр | Значение |
|---|---|
| Название | Теория Вьюненко |
| Система | K3 |
| Основание | \(B=1000=2^3\cdot5^3\) |
| Канонические группы | \(0,\ldots,999\) |
| Разделитель | \(k\) |
| Неотрицательная область | \(\mathbb N_0\) |
| Знаковое расширение | \(\mathbb Z\) |
| Полиномиальная оценка | \(\operatorname{Val}_{K3}(a)=\sum_i a_iB^i\) |
| CRT-разложение на уровне \(r\) | \(\mathbb Z/1000^r\mathbb Z\cong\mathbb Z/2^{3r}\mathbb Z\times\mathbb Z/5^{3r}\mathbb Z\) |
| Пополнение по младшим группам | \(\widehat{\mathbb Z}_{1000}\cong\mathbb Z_2\times\mathbb Z_5\) как топологические кольца |

Основание \(1000\) составное. Поэтому \(\nu_{1000}\) не является мультипликативной \(p\)-адической оценкой, а \(\mathbb Z/1000\mathbb Z\) не является полем. Точные ограничения и доказательства зафиксированы в фундаментальном трактате и главе о составной арифметике.

## Правила математической строгости

1. Аксиомы, определения, предположения, теоремы и гипотезы имеют разные статусы.
2. Любая теорема содержит кванторы, область действия, предпосылки и доказательство.
3. Для новых конструкций указываются сигнатура, семантика, примеры, контрпримеры и классические соответствия.
4. Любое преобразование сопровождается доказательством сохранения заявленного инварианта.
5. Составное основание не наделяется свойствами простого основания без доказательства.
6. Точные вычисления, приближённые оценки и эмпирические наблюдения явно разделяются.
7. Конечный перебор доказывает только полностью исчерпанную конечную область.
8. Новые математические результаты проходят независимую проверку; отрицательные результаты и контрпримеры сохраняются.

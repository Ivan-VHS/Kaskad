## Назначение и границы

Kaskad — постоянный математический исследовательский корпус. Его основной
предмет — Теория Вьюненко K3 и строго определённые математические расширения.
Рабочий цикл:

**вопрос → классический математический контекст → определение → модель →
доказательство или контрпример → точная либо численная проверка следствий →
независимая проверка → документирование результата.**

Kaskad не является проектом операционной системы, языка программирования,
IDE, драйверов, прикладных программ или универсальной программной платформы.
Связи с другими репозиториями допустимы только как математические отношения:
общие определения, отображения, модели, доказуемые следствия и аналогии с
явно указанными границами.

Код и вычислительные инструменты могут применяться как вспомогательные средства
для точной арифметики, конечной проверки, воспроизводимых экспериментов,
контроля документов или формальной верификации. Вычисление не заменяет
математическое доказательство и само по себе не превращает гипотезу в теорему.

## Математическая модель K3

В базовой системе фиксируется составное основание

\[
B=1000=10^3=2^3\cdot5^3.
\]

Канонический каскад задаётся конечным вектором коэффициентов

\[
a=(a_m,\ldots,a_1,a_0),\qquad a_i\in\{0,1,\ldots,999\},
\]

а его числовое значение определяется полиномиальной оценкой

\[
\operatorname{Val}_{K3}(a)=\sum_{i=0}^{m}a_iB^i.
\]

Индекс \(i=0\) соответствует младшей группе. В текстовой записи группы
разделяются символом \(\mathtt{k}\). Символ \(\mathtt{k}\) — лексический
разделитель, а не самостоятельная цифра, множитель или оператор умножения.
Оператор позиционного сдвига \(S_B\) определяется отдельно.

| Параметр | Каноническое значение |
|---|---|
| Система | K3 |
| Основание | \(B=1000=2^3\cdot5^3\) |
| Диапазон канонической группы | \(0\ldots999\) |
| Разделитель групп | \(\mathtt{k}\) |
| Область неотрицательных значений | \(\mathbb N_0\) |
| Знаковое расширение | \(\mathbb Z\) |
| Каноническое слово нуля | \(0\) |
| Пустое слово | Не является канонической записью |

Канонические неотрицательные каскады представляют \(\mathbb N_0\); знаковое
расширение рассматривается отдельно для \(\mathbb Z\). Основание составное,
поэтому свойства простых \(p\)-адических оснований нельзя переносить на K3
без доказательства. В частности, на уровне \(r\) используется разложение

\[
\mathbb Z/1000^r\mathbb Z
\cong
\mathbb Z/2^{3r}\mathbb Z\times\mathbb Z/5^{3r}\mathbb Z,
\]

а соответствующее пополнение описывается как топологическое кольцо
\(\mathbb Z_2\times\mathbb Z_5\), не как поле.

## Статусы математических утверждений

Документы различают определения, постулаты, предположения, леммы, теоремы,
следствия, гипотезы, контрпримеры, исчерпывающую конечную проверку,
вычислительные и эмпирические наблюдения, численные оценки, эвристики,
условные результаты, отклонённые формулировки и исследовательские программы.

Запись в дорожной карте не означает, что результат доказан. Конечный перебор
подтверждает утверждение только на полностью перебранной конечной области.
Эмпирическая закономерность или численная оценка не является универсальным
доказательством. Текстовые доказательства не следует называть машинно
формализованными, пока не опубликована соответствующая формализация.

## Воспроизводимая проверка

Текущий CI проверяет согласованность проектных и математических контрактов,
каноническую семантику K3, обязательные документы и относительные ссылки
README. Это проверка документации и контрактов, а не формальная проверка
математических доказательств и не тест математического вычислительного ядра.

Для локального запуска требуется Node.js 22 — именно эту основную версию
задаёт текущий workflow CI. Скрипт использует встроенные модули Node.js;
установка пакетов не требуется.

~~~bash
git clone https://github.com/Ivan-VHS/Kaskad.git
cd Kaskad
node --version
node scripts/validate-foundation.mjs
~~~

Ожидаемый результат при корректных контрактах и локальных ссылках:

~~~text
Kaskad mathematical scope, K3 notation, algebraic semantics, arithmetic contracts and local links: OK
~~~

Workflow использует GitHub-hosted runner с меткой ubuntu-latest, actions/checkout
v4 и actions/setup-node v4. Это описание текущей CI-конфигурации, а не
полностью зафиксированная среда научного численного эксперимента. Для
исследовательских расчётов следует фиксировать точные версии инструментов,
ревизию исходников, параметры точности и округления, входные данные и их
SHA-256, а для стохастических процедур — PRNG и seed.

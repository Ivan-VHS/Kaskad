# Kaskad — позиционная система счисления с основанием 1000

**Kaskad** — математический исследовательский проект. Его основное направление, **Теория Вьюненко K3**, изучает запись целых чисел группами по три десятичные цифры и математические свойства таких записей.

Цель K3 — точно определить эту запись, описать операции над ней и проверить её свойства, не подменяя доказательства вычислениями.

## K3 за одну минуту

В обычной десятичной записи число 50 000 007 записывается как **50 000 007**. В K3 его можно записать группами по три цифры:

**50k0k7**

Здесь **k** — разделитель групп. Он не означает умножение и сам по себе не является числом.

| Запись | Группы от старшей к младшей | Значение |
|---|---:|---:|
| **7** | (7) | 7 |
| **1k** | (1, 0) | 1 000 |
| **50k0k7** | (50, 0, 7) | 50 000 007 |
| **50k7** | (50, 7) | 50 007 |
| **50k0k** | (50, 0, 0) | 50 000 000 |

Средний ноль в **50k0k7** занимает отдельную позицию. Если его удалить, получится другое число: **50k7 = 50 007**. Поэтому нули и разделители нельзя удалять или переставлять без точного правила и доказательства сохранения нужного свойства.

## Три основных определения

**1. Основание.** В K3 фиксировано основание

\[
B=1000=10^3=2^3\cdot5^3.
\]

Допустимые коэффициенты одной группы:

\[
D_B=\{0,1,\ldots,999\}.
\]

Пример: **50** — допустимый коэффициент. Контрпример: **1000** не может быть коэффициентом одной канонической группы.

**2. Каскадный вектор.** Это конечный набор коэффициентов

\[
a=(a_m,\ldots,a_1,a_0),\qquad a_i\in D_B,
\]

где индекс \(i\) задаёт степень основания. Запись перечисляет группы от старшей к младшей; значение вычисляется от младшей позиции к старшей.

Пример: записи **50k0k7** соответствует вектор \((50,0,7)\). Контрпример: \((50,1000,7)\) не является каноническим каскадным вектором, потому что коэффициент 1000 выходит за допустимый диапазон.

**3. Числовая оценка.** Функция переводит конечный вектор в неотрицательное целое число:

\[
\operatorname{Val}_{K3}:
\bigcup_{m\ge0}D_B^{m+1}\to\mathbb N_0,
\qquad
\operatorname{Val}_{K3}(a)=\sum_{i=0}^{m}a_iB^i.
\]

Пример:

\[
\operatorname{Val}_{K3}(50,0,7)
=50\cdot1000^2+0\cdot1000+7
=50\,000\,007.
\]

Контрпример к неверному чтению: **50k0k7** не равно \(50\cdot7\), а **k** не является множителем.

**Важно различать три объекта:** строку **50k0k7**, вектор \((50,0,7)\) и число \(50\,000\,007\). Они связаны правилом чтения, но это не один и тот же тип объекта.

## Что именно исследует K3

K3 рассматривает конечные позиционные записи, их канонический вид, переносы и заёмы, арифметические операции, делимость, остатки и отдельные топологические расширения.

Числовая арифметика K3 согласуется с обычной арифметикой целых чисел: основание 1000 группирует десятичные цифры по три. Проект не утверждает, что обычные целые числа или их арифметика заменены новой системой. Работа сосредоточена на точном языке записи, позиционной структуре, сохранении нулевых групп и отдельно формализованных расширениях. Сопоставление с известной математикой дано в [классическом математическом обзоре](docs/CLASSICAL_MATHEMATICS_CROSSWALK.md).

В репозитории есть и другие направления. Например, **CV-1** — отдельная математическая модель со своими объектами и определениями. Она не является частью аксиоматики K3 только потому, что документы находятся в одном репозитории.

## Проверка вычислительной реализации

В репозитории есть вспомогательный пакет **src/kaskad_k3/**, тесты в **tests/** и эталонные данные в **tests/vectors/**. Пакет использует стандартную библиотеку Python и не имеет дополнительных runtime-зависимостей. CI-конфигурация предусматривает Python 3.11–3.14.

Запуск из корня репозитория:

~~~bash
PYTHONPATH=src python -m unittest discover -s tests -v
~~~

В Windows PowerShell:

~~~powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
~~~

Тесты проверяют конкретные случаи разбора и форматирования, вычисления коэффициентов, нормализации, арифметики, деления, делимости, сериализации и эталонных векторов. Они не доказывают общие теоремы и не проверяют все математические расширения.

Проверяйте CI для конкретного commit в [GitHub Actions](https://github.com/Ivan-VHS/Kaskad/actions). Для исходной ревизии main — **eac38c147001ea554b3afdad2e659000ef1404e6** — на момент подготовки этой редакции GitHub не вернул записей о status checks. Поэтому здесь не заявляется, что текущая main прошла CI.

## Математический статус

K3 — авторская формальная организация позиционной арифметики с основанием 1000. Её неотрицательные значения изоморфны \(\mathbb N_0\), а знаковое расширение — \(\mathbb Z\). Система не заявляет об отмене стандартной арифметики или об универсальном превосходстве над другими основаниями.

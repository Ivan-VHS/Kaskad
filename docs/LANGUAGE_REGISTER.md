# Реестр языковых редакций научного корпуса Kaskad

> Нормативная основа: [Cascade Edition 1.0.0](SCIENTIFIC_MATHEMATICAL_DOCUMENTATION_STANDARD.md).

> Документ подчиняется [Научному стандарту математической документации — Cascade Edition](SCIENTIFIC_MATHEMATICAL_DOCUMENTATION_STANDARD.md). Этот реестр сообщает фактическое состояние переводов и не приравнивает краткое изложение к полному переводу.

## Легенда

- **RU — исходная редакция:** полный основной текст документа написан на русском языке.
- **EN — исходная редакция:** полный основной текст документа написан на английском языке.
- **4 языка — эквивалентная редакция:** содержательные положения представлены на китайском, английском, русском и украинском языках.
- **Ожидает перевода:** полный текст на соответствующем языке отсутствует.
- **Не применимо:** документ содержит машинно-читаемые данные или конфигурацию без самостоятельного естественно-языкового текста.

## Правило изменения статуса

Статус меняется только после появления полной редакции соответствующего документа и проверки математической эквивалентности. Автоматический перевод без математической сверки не считается завершённой научной редакцией. Перевод не должен менять определения, кванторы, предпосылки, обозначения, эпистемический статус или ссылки.

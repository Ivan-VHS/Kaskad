# Теоремы и леммы

Эта директория предназначена для отдельных записей теорем и лемм после того, как их формулировки и зависимости зафиксированы. Пустая директория не означает, что результат доказан или что он автоматически формализован.

Каждая запись должна содержать:

1. точную формулировку и область действия;
2. все предпосылки, определения и соглашения о нотации;
3. зависимости от ранее установленных утверждений;
4. полное доказательство либо явный статус «схема доказательства»;
5. контрпримеры, ограничения и известные открытые случаи;
6. статус: conjecture, conditional result, theorem, refuted либо другой статус из эпистемического контракта;
7. машинно-проверяемый артефакт и инструкцию запуска, только если реально принят и используется соответствующий proof assistant.

Не переносить сюда гипотезы как доказанные теоремы. Численные проверки и тесты сохраняются в реестре свидетельств и не подменяют доказательство.

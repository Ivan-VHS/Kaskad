# Реестр доказательств и математических свидетельств

Этот каталог отделяет формулировки и доказательства от вычислительных и экспериментальных свидетельств.

## Нормативные правила

- [Формальная эпистемика и система доказательств](../FORMAL_EPISTEMIC_AND_PROOF_FRAMEWORK.md) определяет типы утверждений и требования к доказательной дисциплине.
- [Экспериментальный и эмпирический метод](../EXPERIMENTAL_EMPIRICAL_METHOD.md) описывает воспроизводимые наблюдения и вычислительные исследования.
- [Теория Вьюненко](../VYUNENKO_THEORY.md) остаётся каноническим источником основных определений и результатов.

## Типы записей

| Тип | Что он подтверждает |
|---|---|
| Определение / постулат | Принятое основание теории; не результат доказательства |
| Лемма / теорема / следствие | Утверждение с явно записанными предпосылками и полным обоснованием |
| Контрпример | Точное опровержение указанного общего утверждения |
| Конечная исчерпывающая проверка | Все случаи только в явно заданной конечной области |
| Вычислительное / эмпирическое наблюдение | Результат конкретного воспроизводимого эксперимента |
| Гипотеза / эвристика | Нерешённое или недоказанное предположение |

См. [каталог теорем](theorems/README.md). Наборы тестовых векторов находятся в [tests/vectors](../../tests/vectors/) и сами по себе не являются доказательствами общих утверждений.

# Карта документации Kaskad

> **Редакционное обновление · 2026-11-28:** добавлена навигация по CRT-разложению и бесконечным каскадам K3; исходные права и статусы документов сохранены.

## Как пользоваться атласом

Материалы разделены по роли и уровню зрелости. Канонические документы задают базовую систему K3; исследовательские материалы предлагают новые конструкции; прикладные документы описывают математические модели и соответствия, не подменяя исходные программные проекты.

Метка статуса в этом каталоге — редакционная навигация. При расхождении приоритет имеют точная формулировка и статус, указанные внутри соответствующего документа.

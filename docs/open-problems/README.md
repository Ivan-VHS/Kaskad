# Открытые проблемы, гипотезы и контрпримеры

В этот раздел относятся нерешённые утверждения, вопросы о границах теории, кандидаты на контрпримеры и направления исследования. Гипотезы не должны попадать в канонический список доказанных теорем без полного доказательства.

- [Спекулятивный обзор K-суффикса](../K_SUFFIX_SPECULATIVE_RESEARCH_REVIEW.md) — отдельный исследовательский статус; не менять семантику разделителя (k).
- [Зрелость исследования и путь признания](../RESEARCH_MATURITY_AND_RECOGNITION_PATH.md) — требования к зрелости и внешней проверке.
- [Формальная эпистемика и система доказательств](../FORMAL_EPISTEMIC_AND_PROOF_FRAMEWORK.md) — правила статусов утверждений.

Каждая новая запись должна включать точную формулировку, область действия, контрпримеры и статус. Отсутствие контрпримера не считается доказательством.

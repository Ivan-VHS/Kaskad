# Позиционная различимость каскадов K3 и направленная композиция

**Система:** Теория Вьюненко K3  
**Основание:** \(B=1000\)  
**Объекты:** канонические каскады, сырые позиционные записи, арифметические выражения и упорядоченные композиции  
**Статус:** определения и теоремы; расширение не меняет базовую арифметику K3

## 1. Основное различие

K3-запись задаётся не количеством символов-разделителей, а значениями и позициями всех групп. Поэтому равное количество символов \(k\) не влечёт равенства числовых значений.

Для конечного вектора коэффициентов от младшей позиции к старшей

\[
a=(a_0,a_1,\ldots,a_m),\qquad 0\leq a_i<1000,
\]

значение определяется формулой

\[
\operatorname{Val}_{K3}(a)=\sum_{i=0}^{m}a_iB^i,
\qquad B=1000.
\]

Текстовая запись располагает группы от старшей позиции к младшей. Символ \(k\) отделяет соседние группы. Завершающий \(k\) в каноническом положительном слове обозначает ровно один опущенный нулевой младший коэффициент.

Следует различать четыре величины:

- число символов \(k\);
- число явно записанных групп;
- коэффициенты групп и их позиционные индексы;
- числовое значение всего каскада.

Ни одна из первых двух величин сама по себе не определяет числовое значение.

## 2. Каноническая запись и сырая запись

### 2.1. Канонические группы

Каноническая группа — либо одна цифра \(0\), либо десятичная запись целого числа от \(1\) до \(999\) без ведущих нулей. Поэтому \(0\), \(5\), \(50\), \(400\) являются допустимыми группами, а \(00\), \(05\), \(005\) — нет.

Каноническое K3-слово положительного числа начинается с ненулевой старшей группы. Явная младшая группа, если она присутствует, ненулевая. Нулевая младшая позиция может быть обозначена завершающим разделителем \(k\), который добавляет ровно один неявный нулевой коэффициент.

### 2.2. Сырая интерпретация неканонических групп

Чтобы анализировать неканонические примеры вроде \(5k00k\) и \(5k0\), вводится отдельная функция сырой интерпретации.

Пусть сырая запись состоит из групп \(g_m,\ldots,g_0\), каждая из которых является непустой десятичной строкой длины не более трёх. В сырой записи допускаются ведущие нули внутри группы, но не пустые группы. Через \(\operatorname{dec}(g)\) обозначим обычное десятичное значение строки \(g\).

Если запись не заканчивается \(k\), её сырая оценка равна

\[
\operatorname{RawVal}(g_mk\cdots kg_0)
=\sum_{i=0}^{m}\operatorname{dec}(g_i)B^i.
\]

Если запись заканчивается \(k\), добавляется один неявный нулевой младший коэффициент:

\[
\operatorname{RawVal}(g_mk\cdots kg_0k)
=\sum_{i=0}^{m}\operatorname{dec}(g_i)B^{i+1}.
\]

Эта функция служит только для анализа и нормализации неканонических строк. Она не расширяет множество канонических K3-слов и не делает запись с ведущими нулями канонической.

### 2.3. Нормализация сырой записи

Для любой допустимой сырой строки \(w\) сначала вычисляется целое значение \(\operatorname{RawVal}(w)\), затем строится его единственная каноническая K3-запись:

\[
\operatorname{NormRaw}(w)
=\Phi_{K3}(\operatorname{RawVal}(w)),
\]

где \(\Phi_{K3}\) — каноническое кодирование неотрицательного целого числа.

Равенство сырых значений не означает текстового равенства исходных строк. Нормализация устраняет неканонические варианты представления.

## 3. Пример с одинаковым числом разделителей

Рассмотрим записи

\[
A=50k0k,\qquad W=5k00k.
\]

В обеих строках ровно два символа \(k\). Обе строки содержат две явные группы и один завершающий разделитель, то есть в сырой интерпретации обеим соответствуют три позиционных коэффициента.

Для \(A\):

\[
(50,0,0)_{\text{старшая}\to\text{младшая}},
\]

\[
\operatorname{Val}_{K3}(A)
=50B^2+0B+0
=50\cdot1\,000\,000
=50\,000\,000.
\]

Для \(W\) группа \(00\) неканонична, но её сырое десятичное значение равно нулю:

\[
(5,00,0)_{\text{старшая}\to\text{младшая}},
\]

\[
\operatorname{RawVal}(W)
=5B^2+0B+0
=5\cdot1\,000\,000
=5\,000\,000.
\]

Итак,

\[
\boxed{
\operatorname{Val}_{K3}(50k0k)
=50\,000\,000
}
\]

и

\[
\boxed{
\operatorname{RawVal}(5k00k)
=5\,000\,000.
}
\]

Эти значения различаются в десять раз:

\[
50\,000\,000=10\cdot5\,000\,000.
\]

Разность равна

\[
45\,000\,000=45B^2.
\]

Сырая запись \(5k00k\) нормализуется:

\[
\boxed{\operatorname{NormRaw}(5k00k)=5k0k.}
\]

Каноническое сравнение, следовательно, имеет вид

\[
\boxed{50k0k\ne5k0k.}
\]

### Теорема 1. Число разделителей не является инвариантом числового значения

Существуют две сырые позиционные записи с одинаковым числом разделителей \(k\), но разными числовыми значениями.

**Доказательство.** Записи \(50k0k\) и \(5k00k\) имеют по два разделителя. Их сырые векторы коэффициентов по позициям равны соответственно \((50,0,0)\) и \((5,0,0)\), считая от старшей позиции к младшей. Их оценки равны \(50B^2\) и \(5B^2\), а эти числа различны, поскольку \(50\ne5\). \(\square\)

### Следствие 1

Количество разделителей \(k\) может задавать число переходов между позициями, но не определяет величины коэффициентов и не является достаточным идентификатором каскадного числа.

## 4. Четыре арифметические суммы

Сумма в базовом ядре K3 определяется как обычное сложение целочисленных значений с последующей канонизацией:

\[
u\oplus_{K3}v
=\Phi_{K3}\bigl(\Psi_{K3}(u)+\Psi_{K3}(v)\bigr).
\]

Операция сложения целых чисел коммутативна. Поэтому перестановка слагаемых не меняет числовой результат. Для ясного анализа неканоническую запись \(5k0\) сначала оценим сырой функцией.

### 4.1. Первое выражение: \(5k+5k0\)

Каноническое слово \(5k\) означает

\[
\operatorname{Val}_{K3}(5k)=5B=5\,000.
\]

Сырая запись \(5k0\) имеет две явные группы, младшая из которых равна нулю:

\[
\operatorname{RawVal}(5k0)=5B+0=5\,000.
\]

Поэтому

\[
\begin{aligned}
5\,000+5\,000&=10\,000,\\
10\,000&=10B.
\end{aligned}
\]

Канонический результат:

\[
\boxed{
5k+5k0=10\,000=10k.
}
\]

Здесь запись \(5k0\) неканонична и нормализуется в \(5k\). Поэтому тот же расчёт в строго канонической арифметике имеет вид \(5k+5k=10k\).

### 4.2. Второе выражение: \(5k+50k\)

\[
\operatorname{Val}_{K3}(5k)=5B=5\,000,
\]

\[
\operatorname{Val}_{K3}(50k)=50B=50\,000.
\]

Отсюда

\[
\begin{aligned}
5\,000+50\,000&=55\,000,\\
55\,000&=55B.
\end{aligned}
\]

Канонический результат:

\[
\boxed{
5k+50k=55\,000=55k.
}
\]

### 4.3. Третье выражение: \(50k+5k0\)

\[
\begin{aligned}
50\,000+5\,000&=55\,000,\\
55\,000&=55B.
\end{aligned}
\]

Следовательно,

\[
\boxed{
50k+5k0=55\,000=55k.
}
\]

### 4.4. Четвёртое выражение: \(5k0+50k\)

\[
\begin{aligned}
5\,000+50\,000&=55\,000,\\
55\,000&=55B.
\end{aligned}
\]

Следовательно,

\[
\boxed{
5k0+50k=55\,000=55k.
}
\]

### 4.5. Сводный результат

| Исходная запись | Сырые числовые слагаемые | Значение суммы | Канонический результат |
|---|---:|---:|---|
| \(5k+5k0\) | \(5\,000+5\,000\) | \(10\,000\) | \(10k\) |
| \(5k+50k\) | \(5\,000+50\,000\) | \(55\,000\) | \(55k\) |
| \(50k+5k0\) | \(50\,000+5\,000\) | \(55\,000\) | \(55k\) |
| \(5k0+50k\) | \(5\,000+50\,000\) | \(55\,000\) | \(55k\) |

Таким образом, первая сумма отличается от трёх остальных. Третья и четвёртая записи различаются порядком операндов, но не значением арифметической суммы:

\[
\boxed{
\operatorname{RawVal}(50k)+\operatorname{RawVal}(5k0)
=
\operatorname{RawVal}(5k0)+\operatorname{RawVal}(50k).
}
\]

Это не допущение и не ограничение нотации: равенство следует из коммутативности сложения целых чисел.

## 5. Порядок арифметических операндов и порядок записи выражения

Чтобы сохранить различие между выражениями \(50k+5k0\) и \(5k0+50k\), не нарушая арифметику, вводится понятие упорядоченного синтаксического выражения.

Положим

\[
\operatorname{AddExpr}(A,C)=\langle +,A,C\rangle,
\]

где \(\langle\cdot\rangle\) — упорядоченная структура синтаксического дерева.

Тогда

\[
\operatorname{AddExpr}(50k,5k0)
\ne
\operatorname{AddExpr}(5k0,50k)
\]

как синтаксические объекты, поскольку их левые и правые поддеревья переставлены.

Однако функция вычисления выражения удовлетворяет

\[
\operatorname{Eval}(\operatorname{AddExpr}(A,C))
=
\operatorname{Eval}(\operatorname{AddExpr}(C,A)).
\]

В частности,

\[
\operatorname{Eval}(\operatorname{AddExpr}(50k,5k0))
=
\operatorname{Eval}(\operatorname{AddExpr}(5k0,50k))
=55\,000.
\]

Итак, необходимо различать:

1. **структурное различие выражений:** порядок операндов различен;
2. **числовое равенство выражений:** результат сложения одинаков;
3. **историю вычисления:** последовательность промежуточных действий может различаться и должна храниться отдельно, если она существенна.

Структурное различие не даёт права утверждать, что значения сумм различны.

## 6. Направленная композиция каскадных блоков

Если требуется операция, при которой перестановка каскадных блоков меняет не только структуру, но и числовое значение, вводится самостоятельная операция позиционного присоединения.

Обозначим её

\[
\boxed{\diamond_{K3}}.
\]

Она не является арифметическим сложением.

### 6.1. Определение блока

Положительный каскадный блок задаётся конечной последовательностью групп от старшей к младшей:

\[
A=(a_m,\ldots,a_0),
\qquad
a_m\in\{1,\ldots,999\},
\qquad
a_i\in\{0,\ldots,999\}.
\]

Его длина и значение:

\[
\ell(A)=m+1,
\qquad
V(A)=\sum_{i=0}^{m}a_iB^i.
\]

Если каноническая запись заканчивается \(k\), соответствующий неявный младший нулевой коэффициент включается в блоковый вектор до композиции.

### 6.2. Определение направленного присоединения

Для двух положительных блоков

\[
A=(a_m,\ldots,a_0),
\qquad
C=(c_n,\ldots,c_0)
\]

определим

\[
\boxed{
A\diamond_{K3}C
=
(a_m,\ldots,a_0,c_n,\ldots,c_0).
}
\]

Первый блок занимает старшие позиции, второй — следующие за ним младшие позиции. Ни один коэффициент не складывается с коэффициентом другого блока; перенос не выполняется.

Числовое значение результата:

\[
\boxed{
V(A\diamond_{K3}C)
=
V(A)B^{\ell(C)}+V(C).
}
\]

### 6.3. Первый порядок блоков

Каноническая запись \(50k\) разворачивается в блок

\[
A=(50,0),
\qquad
V(A)=50B=50\,000.
\]

Сырая запись \(5k0\) после интерпретации нулевой младшей группы задаёт блок

\[
C=(5,0),
\qquad
V(C)=5B=5\,000.
\]

Следовательно,

\[
A\diamond_{K3}C=(50,0,5,0).
\]

Каноническая запись результирующего каскада:

\[
50k0k5k.
\]

Его значение:

\[
\begin{aligned}
V(A\diamond_{K3}C)
&=50B^3+0B^2+5B+0\\
&=50\,000\,000\,000+5\,000\\
&=\boxed{50\,000\,005\,000}.
\end{aligned}
\]

### 6.4. Обратный порядок блоков

Теперь

\[
C\diamond_{K3}A=(5,0,50,0).
\]

Каноническая запись:

\[
5k0k50k.
\]

Значение:

\[
\begin{aligned}
V(C\diamond_{K3}A)
&=5B^3+0B^2+50B+0\\
&=5\,000\,000\,000+50\,000\\
&=\boxed{5\,000\,050\,000}.
\end{aligned}
\]

Поэтому

\[
\boxed{
A\diamond_{K3}C\ne C\diamond_{K3}A
}
\]

и числовая разность равна

\[
50\,000\,005\,000-5\,000\,050\,000
=44\,999\,955\,000.
\]

Это точное математическое выражение зависимости результата от порядка позиционных блоков.

## 7. Алгебраические свойства направленной композиции

### Теорема 2. Ассоциативность

Для любых трёх положительных конечных блоков \(A,C,D\):

\[
(A\diamond_{K3}C)\diamond_{K3}D
=
A\diamond_{K3}(C\diamond_{K3}D).
\]

**Доказательство.** Обе части являются конкатенацией одной и той же упорядоченной последовательности коэффициентных блоков:

\[
(A,C,D).
\]

Следовательно, совпадают все коэффициенты на каждой позиции. \(\square\)

### Теорема 3. Аддитивность длины блоков

\[
\boxed{
\ell(A\diamond_{K3}C)
=\ell(A)+\ell(C).
}
\]

**Доказательство.** По определению композиция соединяет все группы первого блока и все группы второго блока без удаления или добавления позиций. \(\square\)

### Теорема 4. Некоммутативность

Операция \(\diamond_{K3}\) некоммутативна в общем случае.

**Доказательство.** Для \(A=(50,0)\), \(C=(5,0)\) выше вычислено:

\[
V(A\diamond_{K3}C)=50\,000\,005\,000,
\]

\[
V(C\diamond_{K3}A)=5\,000\,050\,000.
\]

Числовые значения различны, следовательно, блоки-композиции различны. \(\square\)

### Замечание о нулевом блоке и пустой последовательности

Нулевой каскад \(0\) и пустая последовательность коэффициентов — разные объекты. Нулевой блок имеет одну позицию с коэффициентом \(0\); пустая последовательность не имеет позиций и может использоваться как нейтральный элемент конкатенации в расширенном моноиде блоков. Эти объекты нельзя отождествлять.

## 8. Сравнение трёх операций

| Операция | Обозначение | Порядок операндов | Числовой результат |
|---|---|---|---|
| Арифметическое сложение | \(\oplus_{K3}\) | Не влияет на сумму | Коммутативен |
| Упорядоченная запись сложения | \(\operatorname{AddExpr}(A,C)\) | Сохраняется в синтаксическом дереве | Вычисление коммутативно |
| Направленная композиция блоков | \(\diamond_{K3}\) | Определяет размещение групп | В общем случае некоммутативна |

Принципиально важно, что \(+\) не переопределяется. Новая некоммутативная операция вводится отдельным символом и имеет собственную семантику.

## 9. Формальный принцип позиционной различимости

**Принцип K3-PD (Positional Distinction).**

Каскадная структура задаётся совокупностью

\[
\mathcal K=
(B,\mathbf a,\mathbf i,\mathcal O,\operatorname{NF}),
\]

где:

- \(B=1000\) — фиксированное основание;
- \(\mathbf a\) — упорядоченный вектор коэффициентов;
- \(\mathbf i\) — множество позиционных индексов;
- \(\mathcal O\) — структура порядка операндов и блоков, если она участвует в операции;
- \(\operatorname{NF}\) — правило получения канонической формы.

Числовое значение каскада определяется только позиционными коэффициентами:

\[
V_{K3}(\mathcal K)=\sum_i a_iB^i.
\]

Структурное тождество векторов требует совпадения всех коэффициентов на соответствующих позициях. Тождество арифметических значений слабее структурного тождества, если сравниваются неканонические сырые представления или выражения до нормализации.

Для операций действует следующее разделение:

\[
\begin{aligned}
\text{сложение:}&\quad
V(A\oplus_{K3}C)=V(A)+V(C),\\
\text{синтаксическое упорядочение:}&\quad
\operatorname{AddExpr}(A,C)\ne\operatorname{AddExpr}(C,A)
\ \text{в общем случае},\\
\text{направленная композиция:}&\quad
V(A\diamond_{K3}C)
=V(A)B^{\ell(C)}+V(C).
\end{aligned}
\]

## 10. Контрольные примеры и проверяемые следствия

| Тест | Ожидаемое свойство |
|---|---|
| \(50k0k\) | Канонично; значение \(50\,000\,000\) |
| \(5k00k\) | Неканонично; сырое значение \(5\,000\,000\); нормализация \(5k0k\) |
| \(5k0\) | Неканонично; сырое значение \(5\,000\); нормализация \(5k\) |
| \(5k+5k0\) | Сырая арифметическая сумма \(10\,000\); канон \(10k\) |
| \(5k+50k\) | Сумма \(55\,000\); канон \(55k\) |
| \(50k+5k0\) | Сумма \(55\,000\); канон \(55k\) |
| \(5k0+50k\) | Сумма \(55\,000\); канон \(55k\) |
| \(50k\diamond_{K3}5k0\) | Значение \(50\,000\,005\,000\); канон \(50k0k5k\) |
| \(5k0\diamond_{K3}50k\) | Значение \(5\,000\,050\,000\); канон \(5k0k50k\) |

Теоретические следствия, подлежащие сохранению в дальнейшем развитии K3:

1. число разделителей не определяет коэффициенты;
2. неканоническая строка может иметь однозначную сырую оценку, не становясь каноническим словом;
3. нормализация сохраняет числовое значение;
4. арифметическое сложение остаётся коммутативным;
5. порядок операндов может сохраняться как свойство синтаксического выражения;
6. некоммутативное числовое объединение блоков возможно только как отдельная операция с отдельно заданной семантикой;
7. направленная композиция \(\diamond_{K3}\) ассоциативна и в общем случае некоммутативна.

**Заключение.** Теория Вьюненко K3 различает количество разделителей, количество групп, значения коэффициентов, позиционные индексы, каноничность записи и порядок композиции. В базовой арифметике перестановка слагаемых сохраняет сумму. В направленной композиции каскадных блоков порядок является частью математической операции и может менять числовое значение. Это расширение сохраняет основание \(1000\), допустимые канонические коэффициенты и единственность канонического разложения.

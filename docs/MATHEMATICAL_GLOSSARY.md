# Математический словарь и реестр обозначений Kaskad

> Cascade Edition 1.0.0 · Нормативный навигационно-терминологический документ  
> Редакция: 2026-11-28  
> Область: математический корпус Kaskad; документ не вводит новых аксиом и не заменяет профильные теории.

## 1. Правила употребления

1. Формальное определение в каноническом документе соответствующей теории имеет приоритет над краткой словарной записью.
2. Один символ сохраняет одно значение в пределах одной теории. Совпадающие буквы в разных теориях не означают общего объекта.
3. Термин без формального определения не используется как посылка доказательства.
4. Образные названия сами по себе не задают математический объект.
5. Числовое равенство, равенство векторов и равенство синтаксических деревьев — разные отношения.
6. Неопределённое, отсутствующее, пустое и нулевое значения не отождествляются.

## 2. Основная нотация K3

| Обозначение | Тип / область | Канонический смысл |
|---|---|---|
| \(B\) | Положительное целое | Фиксированное основание K3: \(1000=10^3=2^3\cdot5^3\). |
| \(D_B\) | Конечное множество | Канонический диапазон коэффициента: \(\{0,1,\ldots,999\}\). |
| \(a=(a_0,\ldots,a_m)\) | Конечный вектор | Коэффициенты K3 в порядке от младшей позиции к старшей. |
| \(a_i\) | Целый коэффициент | Коэффициент позиции \(i\), имеющей вес \(B^i\). |
| \(W_{K3}\) | Язык | Множество канонических текстовых слов K3, определяемое грамматикой. |
| \(\operatorname{Val}_{K3}\) | Отображение | Оценка вектора: \(\sum_{i=0}^{m}a_iB^i\). На канонических векторах это биекция с \(\mathbb N_0\). |
| \(\Psi_{K3}\) | Отображение декодирования | Каноническое слово в неотрицательное целое; детали заданы в теории и спецификации синтаксиса. |
| \(\Phi_{K3}\) | Канонизация | Обратное к \(\Psi_{K3}\) кодирование неотрицательного целого каноническим словом. |
| \(k\) | Лексический символ | Разделитель соседних групп. Не является основанием, числом, множителем или оператором умножения. |
| \(S_B\) | Оператор | Отдельно определяемый позиционный сдвиг на одну позицию основания \(B\); не смешивать с символом-разделителем \(k\). |
| \(\delta_{K3}\) | Функция глубины | Глубина канонического положительного каскада; в базовой записи совпадает с числом разделителей. |
| \(P_a(x)\) | Многочлен | \(\sum_{i=0}^{m}a_ix^i\); значение K3 есть \(P_a(B)\). |

### 2.1. Позиции и запись

Коэффициентный вектор индексируется от младшей позиции к старшей. Текстовая запись располагает группы от старшей к младшей. Позицию определяет разделитель **k**, а не число десятичных цифр в группе.

Завершающий **k** в канонической грамматике — специальное сокращение: он обозначает ровно одну неявную младшую нулевую группу. Это правило текстового кодирования не превращает **k** в оператор сдвига. Подробности: [канонический синтаксис K3](K3_CANONICAL_SYNTAX.md).

### 2.2. Режимы входа

| Имя | Назначение | Что сохраняется |
|---|---|---|
| **Canonical** | Строгий разбор канонического слова | Каноническая грамматика и её единственная интерпретация. |
| **K3-PAD** | Явно выбранный импорт с ведущими нулями в токенах | Числовая оценка после нормализации; исходное написание хранится отдельно, если оно нужно вызывающему процессу. |
| **K3-RAW** | Явно выбранный структурный вход | Исходная группировка и структурные данные в пределах спецификации; это не канонический разбор. |

Нельзя молча преобразовывать один режим в другой. Правила равенства и преобразования определены в [структурной семантике и упорядоченных суммах](K3_STRUCTURAL_SEMANTICS_AND_ORDERED_SUMS.md).

### 2.3. Терминальный интеграл K3-TI

| Обозначение | Тип / область | Смысл |
|---|---|---|
| \(\dashv\) | Маркер K3-TI | Указывает на терминальное правое положение интегрального оператора. |
| \(\operatorname{TI}^{\dashv}_{\Omega,\mu}\) | Постфиксный оператор | Принимает заключённое в скобки выражение и возвращает \(\int_\Omega F\,d\mu\). |
| \((\Omega,\mathcal A,\mu)\) | Пространство с мерой | Явно задаёт область, измеримые множества и меру интегрирования. |
| \(\delta_\star\) | Атомарная мера | Единичная масса в специальной точке; в синус-гордоновой модели вес 8 кодирует топологический вклад. |

Нормативный документ: [K3-TI — терминальный интегральный оператор](K3_TERMINAL_INTEGRAL_OPERATOR.md). Терминальная запись не меняет семантику \(k\) или основание \(B=1000\).

## 3. Арифметика и алгебра K3

| Термин | Формальный смысл / ограничение |
|---|---|
| Канонический коэффициентный вектор | Конечный вектор из \(D_B\), у которого старший коэффициент ненулевой при положительном значении; ноль имеет отдельную форму \((0)\). |
| Сырой коэффициентный вектор | Конечный набор целых коэффициентов до нормализации; коэффициенты не обязаны лежать в \(D_B\). |
| Нормализация | Процедура преобразования сырого вектора в канонический, сохраняющая точную взвешенную сумму и завершающаяся при заданных условиях. |
| Перенос / заём | Локальное изменение соседних коэффициентов, основанное на евклидовом делении по \(B\): \(c_i+t_i=Bt_{i+1}+r_i\), \(0\le r_i<B\). |
| Числовое равенство | Равенство результатов функции оценки; не подразумевает равенства исходных строк или деревьев. |
| Структурное равенство | Равенство входных структур в рамках явно заданного типа и режима; может быть строже числового равенства. |
| \(\nu_{1000}(n)\) | Наибольшее \(r\ge0\), для которого \(1000^r\mid n\), при \(n\ne0\); для нуля используется \(\infty\). Функция не является мультипликативной \(p\)-адической оценкой. |
| Единица по модулю \(1000^r\) | Класс \([n]\), обратимый в \(\mathbb Z/1000^r\mathbb Z\); критерий: \(\gcd(n,1000)=1\). |
| CRT-разложение | Изоморфизм, следующий из \(1000^r=2^{3r}5^{3r}\) и китайской теоремы об остатках. |
| \(1000\)-адическое пополнение | Обратный предел \(\varprojlim_r\mathbb Z/1000^r\mathbb Z\); его кольцевая структура сопоставляется с \(\mathbb Z_2\times\mathbb Z_5\) через CRT. |

**Граница новизны.** Числовая функция \(\operatorname{Val}_{K3}\) задаёт обычную позиционную оценку с основанием \(1000\). Поэтому K3 не следует представлять как новую арифметику целых чисел только на основании групповой записи. Исследовательский вклад должен формулироваться в терминах конкретной нотации, структурных профилей, инвариантов, операторов или доказанных расширений.

## 4. CV-1: отдельная теория

Понятия этого раздела принадлежат CV-1 и не являются обозначениями K3.

| Обозначение | Формальное значение |
|---|---|
| \(c\) | Фиксированный параметр из \(\mathbb Z\setminus\{0\}\). |
| \(\prec_c\) | Отношение \(\{(0,c)\}\) на \(\mathbb Z\): \(x\prec_c y\iff x=0\land y=c\). |
| \(\rightsquigarrow_c\) | Отдельное отношение перехода: \(x\rightsquigarrow_c y\iff y=x+c\). |
| Параметрическое отношение | Семейство отношений, зависящее от выбранного \(c\); фиксированный параметр является частью определения. |

Для каждого фиксированного ненулевого \(c\), отношение \(\prec_c\) иррефлексивно: единственная возможная пара \((0,c)\) не рефлексивна, поскольку \(c\ne0\). Оно транзитивно вакуозно: две последовательные пары \((x,y)=(0,c)\) и \((y,z)=(0,c)\) потребовали бы одновременно \(y=c\) и \(y=0\), что невозможно. Следовательно, \(\prec_c\) является строгим частичным порядком, но не линейным порядком на \(\mathbb Z\). Единственная двухэлементная цепь — \(\{0,c\}\); для любого \(x\notin\{0,c\}\) одноэлементная цепь \(\{x\}\) также максимальна по включению. Переход \(\rightsquigarrow_c\) не тождественен отношению \(\prec_c\).

Источник: [Теория Чумного Вердикта CV-1](CHUMNY_VERDICT_THEORY.md). Совместное размещение K3 и CV-1 в репозитории не объединяет их носители, аксиоматики или отношения.

## 5. Эпистемические статусы

Статус относится к конкретному утверждению, а не ко всему документу или репозиторию.

| Статус / тип | Что означает | Чего не означает |
|---|---|---|
| Аксиома / постулат | Принятая исходная посылка внутри явно заданной теории | Доказанность из более ранних посылок |
| Определение | Введение значения термина или объекта | Теорему о существовании или полезности объекта |
| Предположение | Условие, принятое для конкретного вывода | Общепринятую аксиому |
| Лемма / теорема / следствие | Утверждение, выведенное из предпосылок и сопровождаемое доказательством | Независимую экспертизу или машинную проверку |
| Гипотеза / открытая задача | Утверждение, для которого доказательство ещё не установлено | Факт, даже при большом числе тестов |
| Контрпример | Свидетель, опровергающий указанное обобщение в заявленной области | Опровержение всей теории |
| Конечная исчерпывающая проверка | Проверка всех элементов указанной конечной области | Универсальное доказательство |
| Вычислительное наблюдение | Воспроизводимый результат вычисления | Теорему вне области вычисления |
| Прикладная модель | Математическое описание конкретного процесса или системы | Теорему о свойствах всех реализаций |
| Независимая проверка | Проверка лицом, не являющимся автором соответствующего доказательства | Автоматическую гарантию без описания области проверки |
| Машинно проверенное доказательство | Доказательство, принятое указанным proof assistant при фиксированном окружении | Внешнюю публикацию или научный приоритет |

Машиночитаемые значения статусов K3 задаются в [реестре утверждений](K3_CLAIM_REGISTRY.json); словарь не переименовывает и не переопределяет их.

# Большие и расширенные числа Теории Вьюненко

## Конечные каскады, огромные величины, периодические записи, бесконечные пределы и многокомпонентные числа

**Версия:** 0.1.0  
**Статус:** расширенная исследовательская спецификация. Базовое основание \(B=1000\) сохраняется. Семейства ниже разделяют числовой объект и способ его K3-представления.

---

## 1. Базовый конечный каскад

Для \(d\ge1\) определим множество \(d\)-групповых неотрицательных каскадов:

\[
\mathcal K_d=
\{(a_{d-1},\ldots,a_0):0\le a_i<B\}.
\]

Функция значения:

\[
\operatorname{Val}_{K3}(a)=\sum_{i=0}^{d-1}a_iB^i.
\]

Диапазон и максимальное значение:

\[
0\le\operatorname{Val}_{K3}(a)<B^d,
\qquad
M_d=B^d-1.
\]

Число всех векторов длины \(d\):

\[
|\mathcal K_d|=B^d=1000^d.
\]

Все значения от \(0\) до \(B^d-1\) достигаются ровно один раз при фиксированной длине с ведущими нулями. Канонический минимальный синтаксис может опускать ведущие нулевые группы, но это не меняет множество значений.

## 2. Семейство каскадно-больших чисел

Для каждого \(d\) верхняя граница \(M_d=1000^d-1\) показывает, насколько велико число, помещающееся в \(d\) группах. Например:

\[
M_1=999,\qquad
M_2=999999,\qquad
M_3=999999999.
\]

Для группы длины \(d\) максимальная десятичная длина не превосходит \(3d\). Число групп — удобная структурная мера, но не самостоятельная новая мощность числа.

### Рекурсивная башня Вьюненко

Определим последовательность:

\[
T_0=1,\qquad T_{n+1}=1000^{T_n}.
\]

Тогда:

\[
T_1=1000,\quad
T_2=1000^{1000},\quad
T_3=1000^{(1000^{1000})}.
\]

Каждое \(T_n\) при конечном \(n\) — обычное конечное целое число и потому имеет конечную K3-запись. Рекурсивная формула компактно задаёт число, не выписывая все его группы.

Здесь \(T_n\) — авторски определённая последовательность сверхбыстро растущих целых чисел, а не новый класс чисел вне \(\mathbb N\).

## 3. Сравнение роста

Для сравнения разных семейств необходимо фиксировать аргумент и критерий роста. Для функций \(f,g:\mathbb N\to\mathbb N\) можно определить:

\[
f\preceq g
\quad\Longleftrightarrow\quad
\exists C>0\ \exists n_0\
\forall n\ge n_0:\ f(n)\le g(n).
\]

Более строгая асимптотическая доминация:

\[
f\prec g
\quad\Longleftrightarrow\quad
\lim_{n\to\infty}\frac{f(n)}{g(n)}=0,
\]

если предел существует. Это разные отношения; нельзя называть любое большое значение «более быстро растущим» без сравнения функций.

В качестве дальнейшей задачи можно построить K3-индексированную иерархию итераций \(T_n\), но её порядок роста должен выводиться из рекуррентных определений.

## 4. Рациональные K3-числа

Определим рациональное расширение как пары целых K3-значений:

\[
\mathbb Q_{K3}
=
\left\{
\frac{p}{q}:p,q\in\mathbb Z_{K3},\ q>0
\right\}.
\]

Пары \((p,q)\) и \((p',q')\) задают один рациональный объект, если

\[
pq'=p'q.
\]

Операции:

\[
\frac pq+\frac rs=\frac{ps+rq}{qs},
\qquad
\frac pq\cdot\frac rs=\frac{pr}{qs},
\qquad q,s>0.
\]

После факторизации по указанной эквивалентности это обычное поле рациональных чисел с K3-кодированием числителя и знаменателя.

В позиционном основании \(1000\) рациональные дроби имеют конечную или периодическую дробную часть. Конечные разложения — частный случай периодических записей с нулевым хвостом.

## 5. Вещественные K3-записи

Для \(x\ge0\) положим

\[
x=m+\sum_{j=1}^{\infty}b_jB^{-j},
\qquad
m=\lfloor x\rfloor,\quad
b_j\in\{0,\ldots,B-1\}.
\]

Целая часть \(m\) записывается конечным K3-каскадом, дробная часть — бесконечной последовательностью групп.

Чтобы получить каноническую запись, выбираем представление, которое не заканчивается бесконечной последовательностью коэффициентов \(B-1=999\). Это устраняет стандартную неоднозначность между конечной дробью и записью с бесконечным хвостом максимальных коэффициентов.

\[
\mathbb R_{K3}
\]

обозначает вещественные числа, снабжённые такой группировкой и соглашением о канонической записи. По числовой семантике это \(\mathbb R\), а не новое поле.

## 6. Периодические и непериодические каскады

Пусть дробная часть имеет цифры \(b_1,b_2,\ldots\).

- Конечный хвост из нулей задаёт конечную позиционную дробь.
- Периодический хвост задаёт рациональное число.
- В конечном основании рациональное число имеет в итоге периодическую запись.
- Непериодическая запись представляет иррациональное вещественное число при принятом каноническом выборе.

Например:

\[
\frac13=0.\overline{333}_{10}
\]

в десятичной системе, но в K3-группировке период имеет вид повторяющегося блока из трёх десятичных цифр, сгруппированных по три. Это иллюстрация группировки, а не основание для объявления нового числа.

Для произвольного основания \(B=1000\) критерий рациональности формулируется как конечность или периодичность последовательности разрядов после некоторого места.

## 7. Бесконечные каскады по делимости

Определим \(1000\)-адические целые:

\[
\widehat{\mathbb Z}_{1000}
=
\varprojlim_{r}
\mathbb Z/1000^r\mathbb Z
\cong\mathbb Z_2\times\mathbb Z_5.
\]

Элемент задаётся согласованной последовательностью остатков:

\[
x=(x_1,x_2,\ldots),
\qquad
x_{r+1}\equiv x_r\pmod{1000^r}.
\]

Это не то же самое, что бесконечная дробная запись вещественного числа. Здесь близость определяется совпадением всё большего количества младших групп, то есть делимостью разности на большие степени 1000.

Каноническое отображение:

\[
\iota:\mathbb Z\to\widehat{\mathbb Z}_{1000},
\qquad
n\mapsto(n\bmod1000^r)_{r\ge1}
\]

инъективно и имеет плотный образ. Пополнение содержит также элементы, не являющиеся обычными целыми числами.

## 8. Комплексные и гиперкомплексные числа

Комплексное расширение:

\[
\mathbb C_{K3}
=
\{x+\mathbf i y:x,y\in\mathbb R_{K3},\ \mathbf i^2=-1\}.
\]

Многокомпонентное расширение для конечномерной вещественной алгебры \(A\):

\[
\operatorname{MultiK3}_A
=
\left\{
\sum_{j=0}^{n-1}x_je_j:
x_j\in\mathbb R_{K3}
\right\}.
\]

Его операции задаются структурными константами выбранной алгебры. В зависимости от \(A\) умножение может быть коммутативным, некоммутативным или неассоциативным.

## 9. Кандидатные авторские семейства

Для систематизации можно использовать следующие названия, не выдавая их за отдельные известные поля чисел:

| Название | Формальное содержание |
|---|---|
| Каскадно-большие | Целые числа с ограничением или заданной функцией длины K3 |
| Башенные | Последовательность \(T_{n+1}=1000^{T_n}\) |
| Периодические | Рациональные числа с периодическими K3-дробными хвостами |
| Апериодические | Иррациональные вещественные числа в канонической K3-записи |
| \(1000\)-адические | Элементы \(\widehat{\mathbb Z}_{1000}\) |
| Двухкомпонентные | Пары первичных координат из \(\mathbb Z_2\times\mathbb Z_5\) |
| Многокаскадные | Координатные элементы заданной конечномерной алгебры |

Термин «странные числа» допустим как неформальное название раздела, но каждый класс обязан иметь точное определение и операции.

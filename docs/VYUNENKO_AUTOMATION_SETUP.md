# Автоматическая синхронизация Теории Вьюненко

**Статус на 2026-11-28:** механизм добавлен в Kaskad; наличие и корректность межрепозиторного секрета пока не подтверждены.

## Что запускает синхронизацию

Workflow: [`.github/workflows/vyunenko-ecosystem-sync.yml`](../.github/workflows/vyunenko-ecosystem-sync.yml)

Он запускается при обновлении канонической Теории Вьюненко, документа CRT/бесконечных каскадов или реестра зависимостей в `main`. Также доступен `workflow_dispatch` для повторного запуска после настройки доступа.

Скрипт [`scripts/sync_vyunenko_docs.mjs`](../scripts/sync_vyunenko_docs.mjs):

1. читает версию и список связанных репозиториев из `VYUNENKO_ECOSYSTEM_SYNC.v1.json`;
2. обновляет ссылки в существующих локализованных README;
3. создаёт или актуализирует локальную математическую справку и запись в `docs/README.md`;
4. создаёт отдельную ветку и Draft PR в каждом репозитории;
5. обновляет уже существующий PR той же версии вместо создания дубликата.

Скрипт не записывает напрямую в `main`, не импортирует чужой исходный код и не меняет лицензии. Он сохраняет локальные технические границы каждого проекта.

## Однократная настройка доступа

В настройках репозитория **Ivan-VHS/Kaskad** необходимо добавить Actions secret с именем:

`IVAN_VHS_SYNC_TOKEN`

Токен должен иметь минимально необходимые права на пять связанных репозиториев:

- **Contents: Read and write**
- **Pull requests: Read and write**

Поддерживается fine-grained PAT, ограниченный репозиториями Pytyliki, Reaper, OPlague, VentuSample и DAK. Не помещайте токен в файлы, workflow output или README.

Без секрета workflow выполнит только проверку синтаксиса и JSON-реестра, запишет понятное предупреждение в Job Summary и не будет пытаться выполнять межрепозиторные записи. Наличие секрета из данного чата проверить нельзя.

## Политика

- Сначала обновляется канонический Kaskad.
- В смежных репозиториях открываются отдельные Draft PR.
- Проверки каждого репозитория должны завершиться успешно до слияния.
- Слияние выполняется правилами и защитой ветки целевого репозитория.
- Внешние лицензии, авторство, NOTICE и сторонняя атрибуция не переносятся и не заменяются.
- Математические определения и доказательства не редактируются автоматически только ради синхронизации описаний.

**Непрерывная синхронизация считается активной только после добавления секрета и успешного выполнения workflow.**

# Профиль структуры репозитория — Kaskad

**Нормативный стандарт:** [Ivan-VHS Repository Structure Standard](https://github.com/Ivan-VHS/DAK/blob/main/docs/REPOSITORY_STRUCTURE_STANDARD.md).

Kaskad применяет математическую структуру из стандарта, сохраняя уже существующие канонические документы и пути. Новые тематические каталоги служат индексами; они не копируют и не переименовывают существующие главы.

## Каноническое расположение

| Область | Канонический путь | Назначение |
|---|---|---|
| Область и статус | `docs/status-and-scope.md`, `docs/DEVELOPMENT_STATUS.md`, `project-contract.json` | Границы, текущее состояние, область K3 и эпистемические статусы |
| Основания | `docs/foundations/` | Индекс определений, нотации, постулатов, аксиоматики и границ |
| Теория | `docs/theory/`, `docs/VYUNENKO_THEORY.md` | Каноническая теория, арифметика, структура, операции и инварианты |
| Доказательства | `docs/proofs/` | Реестр математических утверждений, доказательств и конечных свидетельств |
| Машинная формализация | `formal/` | Только реальные формальные proof-assistant источники после принятия инструмента |
| Расширения | `docs/extensions/` | Декомпозиции, завершения и явно классифицированные расширения |
| Классические связи | `docs/classical-links/` | Эквивалентности, перекрёстные отображения, источники и атрибуция |
| Открытые проблемы | `docs/open-problems/` | Гипотезы, контрпримеры и нерешённые вопросы |
| Прикладные модели | `docs/applied-models/` | Ограниченные математические отображения в соседние домены |
| Исходный вычислительный код | `src/kaskad_k3/` | Вспомогательная точная реализация вычислений K3 |
| Проверка | `tests/`, `tests/vectors/` | Тесты ядра и канонические контрольные векторы |
| Схемы и происхождение | `schemas/`, `CITATION.cff`, `CITATION.bib` | Версионированные контракты и цитирование |
| Автоматизация | `scripts/`, `.github/workflows/` | Проверки основания, синхронизация и структурная валидация |
| Материалы | `assets/` | Иллюстрации, атласы и материалы с установленным происхождением |

## Математические границы

- Канонический источник K3 — `docs/VYUNENKO_THEORY.md`; навигационные страницы не являются его альтернативными версиями.
- Основание (B=1000), позиционные коэффициенты и лексический разделитель (k) сохраняют семантику, закреплённую в канонических документах и контракте.
- Позиции, нули и разделители нельзя переставлять, удалять или нормализовать без доказательства эквивалентности.
- Вычислительный код и векторы дают проверяемые свидетельства в объявленной области, но не заменяют математическое доказательство.
- Межрепозиторные связи остаются математическими отображениями и не расширяют границы Kaskad до продуктовой разработки.

## Правило изменения путей

Перенос главы должен обновлять все входящие ссылки, каталог `docs/INDEX.md`, локальные тематические индексы, скрипты синхронизации, проверки Markdown, CI и ссылки на доказательные свидетельства в одном PR. Канонические файлы не дублировать.

# Security Policy

Kaskad is a mathematical research repository. Its auxiliary K3 reference
package performs local exact-integer operations and does not make network
requests, execute downloaded content, or modify user data.

Please do not publish credentials, private personal information, or other
sensitive material in a public issue. For a security-sensitive report, use
GitHub's private vulnerability reporting feature when available. For ordinary
correctness defects, open an issue with a minimal reproduction, expected
result, observed result, and the relevant theory or API contract.

Security fixes apply to the current development line. No long-term-support
release series is currently declared.

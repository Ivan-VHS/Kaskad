# Security Policy

Kaskad is a mathematical documentation and reference-implementation project.
The reference package performs local integer calculations and does not make
network requests or execute downloaded content.

## Reporting

Please do not publish credentials, private personal information, or other
sensitive material in a public issue. For a security-sensitive report, use
GitHub's private vulnerability reporting feature for this repository when it is
available. For ordinary correctness defects, open an issue with a minimal
reproduction, the expected result, and the observed result.

## Supported versions

Security fixes are applied to the current development line. The project does
not currently publish a long-term-support release series.

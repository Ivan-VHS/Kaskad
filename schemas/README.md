# Machine-readable schemas

Schemas define data shape and contract boundaries; they do not prove mathematical truth or algorithmic correctness.

- k3-claim-registry.v1.schema.json describes claim IDs, kinds, dependencies, epistemic states, theorem scopes, and counterexample witnesses.
- k3-reference-vectors.v1.schema.json describes exact K3 operands, coefficients, evaluations, input modes, and operation cases.
- oplague-k3-model.v1.schema.json describes the OPlague domain-model contract.
- scientific-review-gate.v1.schema.json describes the auditable 60-criterion scientific-readiness register, its evidence references, statuses and readiness gates.

- k3-self-created-theories.v1.schema.json describes the eight-category, 64-entry K3-SCT-01 research catalogue; schema validation checks data shape, not mathematical maturity.
